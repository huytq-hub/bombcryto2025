# Icons Folder

Thư mục này chứa các pixel art icons cho UI.

## Icons cần thiết

### TopBar (24x24px)
- `scroll.png` - White scroll icon
- `coin.png` - Gold coin icon ✅ (đã có)
- `chest.png` - Brown chest icon

### BottomNav (36x36px)
- `chest.png` - Chest icon
- `shop.png` - Red shop với white stripes
- `house.png` - Brown house với red roof
- `heroes.png` - Silver helmet icon

## Cách tạo icons

Xem `ICONS_GUIDE.md` ở root folder để biết chi tiết.

### Quick guide:
1. Dùng Piskel (https://www.piskelapp.com/)
2. Tạo canvas đúng size (24x24 hoặc 36x36)
3. Vẽ pixel art icons
4. Export PNG với transparency
5. Đặt vào đây

## Fallback

Nếu không có icon, components sẽ hiển thị emoji tạm thời.
